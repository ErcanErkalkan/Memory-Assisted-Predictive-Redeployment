# Supplementary Reproducibility Materials

This directory contains the supplementary material for the manuscript "Selection-Filtered Predictive Redeployment for Rapid Recovery in Dynamic Multi-Objective Evolutionary Optimization".

## Directory layout

- `data/`: No external input dataset is required. The benchmark cases are generated by the supplied scripts. This directory is retained for optional regenerated raw outputs.
- `scripts/`: Python scripts used to define benchmarks, run experiments, regenerate diagnostics, generate tables, and create figures.
- `results/`: Stored CSV/JSON/TXT outputs used for manuscript tables, statistical tests, recovery audits, source diagnostics, evaluation-count audits, ablation, quota sensitivity, prediction-noise stress, and scalability diagnostics.
- `figures/`: Figure files associated with manuscript and supplementary diagnostics.
- `tables/`: Extended LaTeX tables moved out of the main manuscript to reduce main-text density.

## Main execution examples

Run the main experiment and write outputs to `results/`:

```bash
python scripts/dynamic_prr_experiment.py --mode all --out-dir results
```

Run PRR source diagnostics:

```bash
python scripts/run_prr_source_diagnostics.py
```

Run the recovery audit:

```bash
python scripts/recovery_audit.py
```

Run quota sensitivity and prediction-noise diagnostics:

```bash
python scripts/prr_quota_sensitivity.py
python scripts/prr_prediction_noise_stress.py
```

## Figure-generation note

The manuscript-facing conceptual figures `prr_dynamic_setting.pdf` and `prr_selection_filter_detail.pdf` are deterministic Matplotlib vector drawings generated by `scripts/make_conceptual_vector_figures.py`. They are explanatory diagrams and do not add numerical results.

## Notes

The stored result files are included so that the manuscript tables and figures can be inspected without rerunning the full experiment. Extended diagnostic tables are stored under `tables/` and the corresponding CSV/JSON outputs are stored under `results/`. No numerical rows are included for recent methods that were discussed only for literature positioning and were not generated by the supplied code.
